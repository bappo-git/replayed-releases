# Replayed

Deine Gaming-Clips. Deine Bibliothek. Sortiert nach Spiel und Session, mit Vorschau, Favoriten, Tags, Schnitt und Discord-Export. Funktioniert mit Aufnahmen aus Outplayed, ShadowPlay, Medal und OBS. Nimmt selbst nichts auf und verändert deine Videos nicht. Kein Konto, keine Werbung, nichts läuft im Hintergrund.

**Download:** immer die neueste Version unter [Releases](../../releases/latest). Dort die Datei `Replayed-Setup-<Version>.exe` laden. Windows 10 oder 11, 64-bit.

## Installation

1. Installer starten. Windows zeigt „Der Computer wurde durch Windows geschützt“, weil die App nicht signiert ist. Auf **Weitere Informationen** → **Trotzdem ausführen**. Kommt nur einmal.
2. Beim ersten Start den Ordner mit deinen Clips wählen, zum Beispiel `C:\Users\DU\Videos\Overwolf\Outplayed`. Nicht das ganze Laufwerk, sonst dauert der Scan ewig.
3. „Bibliothek aufbauen“ klicken. Vorschaubilder entstehen danach im Hintergrund.

Neue Versionen einfach über die alte installieren, Einstellungen und Bibliothek bleiben erhalten.

## Gut zu wissen

- Replayed legt im Clip-Ordner einen Ordner `.replayed` an (Favoriten, Tags, Vorschaubilder, Papierkorb). Sonst nichts. Unter Einstellungen → Datenablage siehst du alles und kannst es wieder entfernen.
- Löschen ist echt: Clips im Papierkorb sind nach 3 Tagen weg, „Sofort löschen“ im Disk-Cleaner sofort. Beides fragt vorher nach.
- Probleme: Einstellungen → „Problem melden“ erzeugt einen Bericht auf dem Desktop. Den zusammen mit einem Screenshot schicken.
